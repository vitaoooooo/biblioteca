# Sistema de Biblioteca

Projeto em Java desenvolvido para praticar programação orientada a objetos, organização em camadas, CRUD, repositories, services e regras de negócio.

## Funcionalidades

- Cadastro de livros
- Busca de livros
- Listagem de livros
- Remoção de livros
- Cadastro de clientes
- Busca de clientes
- Listagem de clientes
- Remoção de clientes
- Empréstimo de livros
- Devolução de livros
- Listagem de empréstimos ativos
- Listagem de empréstimos atrasados

## Tecnologias utilizadas

- Java
- Git
- GitHub
- IntelliJ IDEA
